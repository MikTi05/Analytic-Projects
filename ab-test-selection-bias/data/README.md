# Описание данных

`ab_test_data.xlsx` — анонимизированный учебный датасет на уровне клиента.

## Структура

| Поле | Описание |
|---|---|
| индекс | технический идентификатор строки/клиента |
| `gender` | категория пола: `man` или `woman` |
| `OS` | мобильная операционная система: `Android` или `iOS` |
| `month1`–`month17` | месячная выручка клиента до запуска изменения |
| `month18` | выручка клиента в тестовом месяце |
| `b_group` | `yes` — назначен в пилот, `no` — контроль |

В наборе 30 000 строк, пропусков нет. Значения выручки неотрицательны; ноль означает отсутствие выручки в соответствующем месяце.

## Происхождение и использование

Датасет был предоставлен вместе с учебным заданием. Публичный первоисточник, денежная единица и лицензия не указаны. Персональных идентификаторов в файле нет, однако перед публичным распространением следует отдельно подтвердить право публикации.
