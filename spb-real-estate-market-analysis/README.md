# Анализ рынка недвижимости Санкт-Петербурга

Исследовательский анализ 23,7 тыс. объявлений о продаже квартир в Санкт-Петербурге и Ленинградской области. Проект охватывает полный аналитический цикл: проверку качества данных, предобработку, EDA, построение новых признаков и статистическую проверку гипотез.

## Задачи проекта

- определить факторы, связанные со стоимостью квартиры и ценой квадратного метра;
- изучить сроки продажи, сезонность и географические различия рынка;
- проверить статистически значимые различия между сегментами;
- сформулировать выводы, применимые для оценки недвижимости и продуктовой аналитики.

## Данные

В датасете 23 699 объявлений и 22 признака: стоимость, площадь, число комнат, этаж, дата публикации, срок экспозиции, населённый пункт, расстояние до центра и другие характеристики объекта и окружения.

Файл `data.csv` включён в репозиторий для воспроизводимости. Данные используются в учебных целях. Перед повторным распространением датасета следует уточнить его первоначальный источник и условия лицензии.

## Инструменты и методы

- Python, pandas, NumPy;
- Matplotlib и Seaborn;
- корреляционный анализ Пирсона;
- t-тест Уэлча и z-тест долей;
- U-тест Манна — Уитни;
- бутстрап доверительного интервала для разницы медиан.

## Основные результаты

- площадь и география оказались главными факторами стоимости: корреляция цены с общей площадью составляет около 0,77;
- цена квадратного метра снижается по мере удаления от центра примерно до 10–12 км, после чего выходит на плато;
- квадратный метр в Санкт-Петербурге в среднем примерно на 60% дороже, чем в области;
- квартиры на первом этаже имеют дисконт около 19% к средним этажам; результат подтверждён бутстрапом;
- доля быстрых продаж в Санкт-Петербурге выше: около 26% против 22% в области;
- квартиры в центре продаются дольше: медиана около 143 дней против 92 дней за пределами центра;
- в публикациях заметна сезонность: активность выше весной и осенью и ниже летом и в январе.

Статистические выводы сделаны при уровне значимости `α = 0.05`. Подробные расчёты, графики и интерпретация находятся в ноутбуке.

## Как запустить

1. Клонировать репозиторий и перейти в его каталог.
2. Создать и активировать виртуальное окружение:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустить Jupyter Lab:

   ```bash
   jupyter lab
   ```

5. Открыть `real_estate_market_analysis.ipynb` и выполнить все ячейки по порядку.

Проект выполнен как портфолио-кейс для позиции стажёра-аналитика данных.
